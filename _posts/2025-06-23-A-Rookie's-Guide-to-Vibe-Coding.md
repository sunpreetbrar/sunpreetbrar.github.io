### Vibe Coding Slot Machine

It seemed too good for me. I felt now I can just design the products I want and have AI build them. Which is partly true. But as it has been well documented. AI hallucinates, creates new problems trying to solve old ones, goes round and round with no progress. It breaks existing code. 

For someone who doesn't understand coding that much - it all seems like a black box. You put a prompt in, run the code. Things might work or not. If it works; great! enjoy the dopamine and move on to the next thing, if it doesn't you run the slot machine again. 

Hoping it to fix things, and not break the existing stuff.

As the piece of code becomes larger and larger, you loose your already limited understanding of it. The more reliant you are on AI. Your autonomy becomes limited. You just hope AI understands things. While it writes unmaintainable code you just sit and wait. To play the slot machine gamble again. 

Hours on end. I found it hard to get up, because what if my next prompt fixed everything? Or my next prompt adds a new feature that you so much want (Hint: the list of features you want to add, never really ends)

This anticipation of reward is what makes our brain chemicals go crazy. Making us hooked to a slot machine, or a prompt bar on bottom left of an IDE -- whose code you do not understand.

You also ended up learning nothing really in this way. Spending hours running code, copying pasting errors and not using your cognitive abilities sounds like bitch work. It is exactly that.

### A Better Way To Use AI

Now well, its not that bad still. I have made working prototypes in weeks. I would've spent MONTHS if I did caveman coding. I am afraid I would've ever finished it.

A good way to use AI while developing is using it in agent mode. Instead of prompting in the message bar, write code and comments -- let AI help you finish them. This way you do not loose track of the code. It's hard to read and understand 600 lines of AI written code in one go. Especially for unexperienced people like me. But this ensures your own brain is being used.
